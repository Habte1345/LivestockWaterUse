# LivestockWaterUse

County-level livestock water consumption and withdrawal for the
conterminous United States, for dairy cattle, beef cattle, hogs and
poultry.

The repository contains the extraction, modelling and plotting code. All
data products are regenerated by running the pipeline; none are tracked
in git.

matplotlib  seaborn  cartopy  geopandas

## Pipeline

Run in this order.

| # | Script | Reads | Writes to `data/` |
|---|---|---|---|
| 1 | `extract_usgs_livestock.py` | USGS Water Use (web) | `usgs_ls_state_county_1960_2015/` |
| 2 | `usda_livestock.py` | USDA NASS census (web) | `usda_census/` |
| 3 | `era5_climate_GEE.py` | ERA5-Land via Earth Engine | `climate/` |
| 4 | `wcc_mlr.py` | — | `wcc_mlr/` |
| 5 | `wcc_ann_downscale.py` | 2, 3, 4 | `wcc_county/` |
| 6 | `ratio_ann_downscale.py` | 1, 3 | `ratio_county/` |
| 7 | `county_level_WC.py` | 2, 5 | `wc_county/` |
| 8 | `validate_against_usgs.py` | 1, 6, 7 | `validation/` |

### Common options

| Option | Applies to | Purpose |
|---|---|---|
| `--data-dir` | all | redirect output |
| `--verbose` | most | full diagnostics to console |
| `--project` | 3 | Earth Engine Cloud project (required) |
| `--start`, `--end` | 3 | restrict the year span |
| `--n-samples`, `--seed` | 4, 5 | sample size and reproducibility |
| `--hidden`, `--max-iter` | 5, 6 | network shape and epoch cap |
| `--interpolate` | 7 | fill years between agricultural censuses |

`--interpolate` on step 7 is required for step 8. Without it the modelled
series covers census years only, which do not overlap the USGS comparison
years.

## Data

`data/` is gitignored. Everything in it is regenerated by the pipeline.

| Directory | Contents |
|---|---|
| `usgs_ls_state_county_1960_2015/` | USGS livestock withdrawal, consumption, ratio |
| `usda_census/` | county head counts and herd composition |
| `climate/` | one table per forcing, county and state |
| `wcc_mlr/` | coefficients, equations, samples |
| `wcc_county/` | county water consumption coefficients |
| `ratio_county/` | county consumption-to-withdrawal ratios |
| `wc_county/` | county water consumption |
| `validation/` | modelled vs observed, and metrics |

### File conventions

- **Feather** throughout, read with `pandas.read_feather`.
- Keyed on **5-character county FIPS** (`fips`) and 2-character
  `state_fips`, so tables join directly to one another.
- Missing values stay **NaN**, never zero-filled. Run summaries report the
  counts.
- Provenance columns where a value is not a direct observation:
  `head_origin`, `base_source`, `county_name_source`.

### External sources

| Source | Retrieved by |
|---|---|
| USGS National Water Use | step 1, from ScienceBase and the USGS site |
| USDA NASS Census of Agriculture | step 2, from `nass.usda.gov/datasets` |
| ERA5-Land Monthly Aggregated | step 3, via Google Earth Engine |
| Census TIGER boundaries | figure scripts, from `census.gov` |

Steps 1 and 2 download to a local cache and skip files already present.
Step 3 holds results in memory and writes only the cleaned tables.

## Reproducibility

- Sampling and model fitting are seeded; `--seed` gives byte-identical
  output across runs.
- Published equations are checked against their source worked examples at
  import, and the module refuses to run if they do not reproduce.
- Source band and column names are validated against the live datasets, so
  an upstream rename fails immediately rather than producing empty
  columns.

## Troubleshooting

**`SystemExit: 0` under `%run`** — harmless, but call the function
instead: `from <module> import plot; plot()`.

**A figure does not appear in Jupyter** — the figure scripts encode the
PNG themselves and do not depend on `%matplotlib inline`. If nothing
shows, confirm the script is the current version.

**`--f=...kernel.json` in the arguments** — Jupyter injects this. The
scripts use `allow_abbrev=False` and ignore it.

**A stale module after editing a script** — `importlib` caches modules.
Restart the kernel.

**`FileNotFoundError` naming a `data/` table** — an earlier pipeline step
has not been run. The message names the script to run.
